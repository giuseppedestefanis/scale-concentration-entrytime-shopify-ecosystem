# Conventions

Rules for everything in this package. They exist so that every number, figure, and table in the paper can be regenerated by anyone from the raw inputs with one command.

1. **Every artefact comes from a script.** No figure, table, or reported number is ever produced or edited by hand. If a value appears in the paper, a script in `scripts/` prints or writes it.
2. **Numbered pipeline.** Scripts are named `NN_short_name.py` and run correctly in numeric order via `make all`. A script may only read raw inputs or artefacts produced by lower-numbered scripts.
3. **Shared code lives in `common.py`.** Paths, loaders, and constants are defined once. Scripts never hard-code absolute paths; raw-data locations come from `common.py` (env-var overridable).
4. **Outputs are disposable.** Everything in `data/derived/`, `figures/`, `tables/`, `results/` can be deleted and regenerated (`make clean && make all`). Nothing in those folders is edited manually.
5. **Determinism.** Any stochastic step (sampling, bootstrap, ML) sets an explicit seed defined in `common.py`.
6. **One script, one purpose.** A script produces one coherent set of artefacts (e.g. "build the linked panel", "figure: deprecation event study"). Figure scripts are separate from computation scripts where practical: computation writes derived data, the figure script reads it.
7. **Self-describing outputs.** Every derived dataset gets a short entry in `data/README.md` (what it is, which script makes it, one row = what). Every results memo states which script produced it.
8. **Raw data is read-only.** Scripts never write inside the raw data directories. Raw files are documented, with row counts and checksums, in `data/README.md` and verified by `scripts/00_validate_inputs.py`.
9. **Pinned environment.** All dependencies are pinned in `requirements.txt`. Adding a dependency means pinning it there in the same change.
10. **Figures follow the paper's style** and are written as both PDF (for LaTeX) and PNG (for inspection), at publication resolution, from the same script.
